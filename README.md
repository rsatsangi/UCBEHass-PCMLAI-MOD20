## Overview

This repository contains my submission for **Module 20** of the **UC
Berkeley Professional Certificate in Machine Learning & Artificial
Intelligence**.

The project demonstrates an end-to-end supervised machine learning
workflow including data preprocessing, exploratory data analysis,
feature engineering, model training, hyperparameter optimization,
evaluation, and model comparison.

## Project Objectives

-   Data cleaning and preprocessing
-   Exploratory Data Analysis (EDA)
-   Feature engineering
-   Train and compare multiple classification models
-   Hyperparameter optimization
-   Performance evaluation
-   Feature importance analysis

## Models
